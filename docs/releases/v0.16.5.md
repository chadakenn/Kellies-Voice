# Kellie's Voice v0.16.5

**Community test release:** Five fixes from community reports #67–#71.
The release is intentionally public so testers can use the built-in
**Check for app updates** flow. Automated Android tests, Home Assistant
event tests and HACS validation passed. Real-device testing is ongoing.

## Changes

- **#67:** Software-only live camera decoder by default on Android TV.
  Protect HDMI/video playback on integrated TVs; hardware decoder remains
  an advanced opt-in, with an honest snapshot fallback.
- **#68:** New authenticated scoped alert WebSocket for Home Assistant
  non-admin users. Read access to the paired TV's alert-position entity
  is required.
- **#69:** Per-TV **TV alert receiver connected** binary sensor and
  `last_seen_since_ha_start` diagnostic. The indicator tracks authenticated
  alert subscriptions, **not** individual popup delivery acknowledgments.
- **#70:** `show_camera` now supports `show_header: false`,
  `image_fit: fit`, and bounded `refresh_seconds` 2–30. Identical
  snapshot commands reuse their existing popup for less flicker.
- **#71:** Detect when the TV only exposes non-microphone input routes
  and show actionable instructions. A diagnostic override is available
  when Android firmware reports microphone routing incorrectly.

## Installation and feedback

**Update the Android TV app and the matching HACS integration to v0.16.5.**
The Home Assistant integration must be restarted after updating.
Do not uninstall the existing Android app; the signed update should install
in place and retain the saved Home Assistant connection.

Known limitations: Philips Android TV hardware compatibility, dedicated
non-admin token behavior, and USB microphone capture still need physical
tests. Vendor-restricted Google TV remote microphones cannot be unlocked by
a normal Android app. A successful HA action means its event was published,
not necessarily displayed on the television.

If you find a regression, please post your device/firmware/version and
redacted logs on the original [issues page](https://github.com/chadakenn/Kellies-Voice/issues).
Do not include tokens or unredacted camera credentials.
