# Kellie's Voice v0.17.5

Maintenance release for the Home Assistant pairing review, with matching Android TV and Home Assistant versions.

- Android TV: `versionCode 63`, `versionName 0.17.5` (no TV UI feature changes).
- Home Assistant HACS integration: `0.17.5`.

## Fixes

- **Secure Home Assistant-first pairing:** Use the canonical `v3/pairing_v3_wire.py` transport in the production config flow. The old transport refused `/v3/pair/owner-receipt`, `/v3/pair/token-stage`, and `/v3/pair/token-commit`, making approved v3 pairing fail after the one-time owner claim was consumed. Removed the three stale duplicate modules to prevent another drift.
- **Home Assistant responsiveness:** Move P-256 key initialization and ECDH work for comparison codes, remote approval proof, owner receipts, and credential handoff to Home Assistant's executor.
- **Regression protection:** Add tests for actual allowed owner/token routes, the production import, executor-backed ECDH and updated canonical Python fixture paths.

## Compatibility and validation

Existing paired TVs and legacy manual pairing are not intentionally changed. If a previous secure pairing attempt failed, start a **new** two-minute pairing session; the consumed one-shot owner claim is not restored.

CI and offline synthetic pairing tests do not replace verification of a fresh Home Assistant-first pairing on a real TV. A full fresh-install TV hardware test is still required before claiming universal compatibility.

## Upgrade

Update Kellie's Voice in HACS to `0.17.5` and restart Home Assistant. The TV app can be upgraded using the **officially signed** `0.17.5` APK or signed in-app updater after the GitHub Release is published. Install over the existing app; **do not uninstall or clear app data**. Existing connected TVs do not need re-pairing.
