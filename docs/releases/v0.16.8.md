# Kellie's Voice v0.16.8

**Community verification release, October 24, 2026.** The maintainer wants
fixes available through the normal signed TV app updater before wider
physical device acceptance. This release also carries forward v0.16.7
timer OK/Dismiss and live-camera improvements.

## What's new

- **#71 / merged PR #82:** Fix the follow-up Philips 65PUS8507/12 microphone
  false-positive. Android may report Echo Reference In, line_in or remote
  submix with no usable microphone. A strict allowlist now admits only
  recognized built-in, USB, wired-headset and Bluetooth speech-capable
  audio input types. Unknown, line-level, echo-reference and TV-audio
  inputs can no longer silently start Assist recording. Existing explicit
  user **Try unverified microphone** override remains available for unusual
  firmware; it cannot unlock Google remote microphones.
- **#52 / merged PR #53:** The main full-screen Kellie's Voice interface,
  Settings dialogs, diagnostics and compatible splash accents follow the
  selected Overlay style palette (Copper Glass, Compact Charcoal, Night
  Signal or Aurora Glass). HA style updates repaint the visible main screen
  without discarding text, Assist state or remote focus. Local style choice
  updates immediately. The approved brand elements remain unchanged.
- **#68:** Already fixed and physically confirmed in v0.16.5 by a community
  tester using a non-admin HA user. The original issue is closed. Changing
  HA entity-level read permissions at runtime was not physically tested;
  avoid claiming that separate permission edge case was verified.

## How to update

On Android TV: **Kellie's Voice → Settings → Check for app updates**.
Install **v0.16.8, versionCode 25** over the existing signed APK without
uninstalling. Update HACS Kellie's Voice to **v0.16.8** and restart Home
Assistant for a matching integration.
