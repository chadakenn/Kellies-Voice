# Kellie's Voice v0.17.3

**Android TV:** signed versionCode 58. **Home Assistant integration:** 0.17.3.

This maintenance update delivers [PR #298](https://github.com/chadakenn/Kellies-Voice/pull/298), with the following fixes:

- **Actually compact Small voice overlay:** shrinks the reserved answer region, waveform, panel padding, buttons, and width for the Small layout, including Neon Obsidian. Longer responses remain scrollable with the remote; Medium and Large use their previous layout.
- **Community themes in Home Assistant:** fixes the rejected installed-theme-list update caused by routing the theme inventory through Frigate-only validation. The Home Assistant integration validates and accepts bounded printable theme names; camera URL and entity validation stays strict.
- Adds regression tests for accepted and rejected community theme inventory values.

**Update both components:** install the signed Android `app-release.apk` over your current Kellie's Voice app (or use the in-app updater once this GitHub Release is published); update the Kellie's Voice custom integration in HACS to 0.17.3 and restart Home Assistant. Keep app data, your paired TV and preferences. **Do not uninstall or re-pair.**

This release does not itself change Home Assistant automations or device areas. Source CI and integration validation passed on PR #298; actual Small-overlay geometry on each TV/display must still be checked after installation. The owner previously verified CleanMyTV/Ambient Mode compatibility on an onn 4K Pro; this change targets the voice overlay, not the screensaver.
