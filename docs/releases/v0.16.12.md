# Kellie's Voice v0.16.12

**Release date:** October 26, 2026 · **Android versionCode:** 50 · **Home Assistant integration:** 0.16.12

This stable release promotes the opt-in Frigate/HA camera screensaver, live four-camera dashboard and selected full-screen audio after testing on the maintainer's onn Google TV. Kellie's Voice still uses your own Home Assistant Assist pipeline and has **no mandatory wake word** or bundled Ollama model.

## What's new

- **Automatic camera screensaver:** Opt-in camera dashboard over the Android/Google TV screensaver. Select up to four Home Assistant camera entities from the paired TV's HA device controls; Frigate web URL remains an alternative with priority when configured. Snapshot-only mode remains the default and reliable fallback.
- **Live HA grid:** Explicit **HA camera grid playback** choices (Snapshots, Live 1, Live 2, Live 4 advanced); HLS is authenticated and subject to safe decoder constraints and timeout/snapshot fallback. The overview's four streams stay muted.
- **Full-screen with sound on demand:** D-pad highlights a selected camera. Press OK for a full-screen view with **that camera's audio** only if the HLS stream actually contains an audio track. Other cameras stay muted, and no microphone starts. Back returns to the four-tile silent grid; Close exits entirely. Gold focus borders show which footer button will respond to OK.
- **Fixes validated on the owner's TV:** Manual resync recovered the original settings watcher during development. Afterwards four moving streams appeared automatically at idle and returned after reboot without manual resync. The owner confirmed live Doorbell full-screen **with audible sound** and subsequently confirmed remote Back and button highlights work in signed dev.10.
- **More usable grid:** Removes duplicated bottom space reservation to make room for camera tiles while retaining a Close-control footer, subject to individual TV resolution and aspect ratio.
- **Documentation:** Screenshot gallery, Home Assistant setup, troubleshooting and developer notes; private household camera imagery is pixelated in public photos. Screensaver setup and permissions are documented in [Frigate screensaver guide](../FRIGATE_SCREENSAVER.md).

## Hardware testing and limitations

**Confirmed hardware:** onn 4K Pro / Google TV, four live moving cameras, automatic ambient/screensaver launch, reboot recovery, selected Doorbell HLS video + sound, remote Back and visual button focus. This is *not* proof that all TV models, decoders, streams, web views or remote microphones work. Audio requires a source HLS audio track; snapshots have no sound. Four software-decoded HLS streams can tax weaker TV devices; begin with one or two. Frigate website mode is separate from the HA camera grid.

**Still in progress:** Philips/mic detection [#71](https://github.com/chadakenn/Kellies-Voice/issues/71), Fire TV sideload compatibility [#41](https://github.com/chadakenn/Kellies-Voice/issues/41), native TV timer routing [#57](https://github.com/chadakenn/Kellies-Voice/issues/57), manual pairing corner cases [#69](https://github.com/chadakenn/Kellies-Voice/issues/69), and further optional development update-channel verification [#92](https://github.com/chadakenn/Kellies-Voice/issues/92). The opt-in `Okay Nabu` wake-word PR #59 is **not part of this stable release**. Some experimental features remain configurable/off by default and have not been accepted across other TVs.

## Install or upgrade

1. Download signed `app-release.apk` from [GitHub v0.16.12](https://github.com/chadakenn/Kellies-Voice/releases/tag/v0.16.12). Install **over** an existing signed Kellie's Voice app, including dev.10 (build 49), without uninstalling or clearing saved credentials. Signed stable build 50 has the same application ID and release-signing key.
2. In Home Assistant HACS, install the **matching v0.16.12** Kellie's Voice integration from this repository and restart Home Assistant. HACS does *not* install the TV APK.
3. On TV turn on **Frigate screensaver** and **Home Assistant layout**, grant Android **Display over other apps**, and select the cameras via the TV's Home Assistant device controls. Leave **Frigate web URL blank** for the HA-selected grid. Start with **Live (one camera)**, and increase to two or four only if video is reliable. Acknowledge the performance caveat for four streams.
4. For a blank dashboard, open **Settings → Frigate screensaver → Screensaver status & permissions** and **Resync HA cameras**, then retest. The viewer never needs to activate the TV microphone.

For first-time setup, see [Installation](../INSTALL.md), [Frigate screensaver setup](../FRIGATE_SCREENSAVER.md), and the [Wiki](../wiki/Home.md). Screenshots of private home feeds are intentionally redacted.

## Security and rollout

This release must be signed with the same permanent keystore as previous stable builds, and ship both **`app-release.apk`** and **`update.json`** containing the checksum. Updates still require standard Android installation approval. Home Assistant token and camera stream URLs should never be posted publicly.

Feedback and device-specific reports: [GitHub issues](https://github.com/chadakenn/Kellies-Voice/issues). See [public release tracker #141](https://github.com/chadakenn/Kellies-Voice/issues/141).
