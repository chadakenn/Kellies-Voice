# Kellie's Voice v0.16.10

## What's fixed
- **Automatic TV alerts after Home Assistant restarts.** The Android TV alert
  receiver now retries the modern `kellies_voice/subscribe_alerts` WebSocket
  command when HA Core authenticates the TV before the HACS integration has
  finished registering the command. Previously the app fell back immediately
  to older privileged event subscriptions, then got stuck on "Permission denied".
- **Recover from legacy event subscription denial.** Old event-subscription
  permissions do not permanently prevent a fresh, individually authorized
  scoped subscription. Normal Home Assistant read permissions are still enforced.
- **Separate connection indicators.** The main TV screen distinguishes
  Home Assistant voice from TV alerts. Settings → TV alert status displays
  redacted "Last receiver activity" diagnostics. No credentials or token
  values are shown.
- **Independent retry monitor.** A stopped or overdue reconnect callback can
  be repaired while the opted-in foreground receiver is running. Opt-out,
  missing overlay permission, invalid login and terminal denied actions
  remain protected.

## Real hardware acceptance (October 25, 2026)
On an **onn 4K Pro** with signed test build `0.16.10-dev.4`, Home Assistant
Core restart caused the receiver to disconnect and then reconnect without
pressing Resume TV alerts: **83 seconds awake** and **74 seconds with the Google
TV screensaver showing**. The owner confirmed a *new announcement displayed
on the TV* after both recoveries, including over the screensaver.

The public release uses **versionName 0.16.10, versionCode 31**, so it
can upgrade in place from dev.4 (code 30). No uninstall or storage wipe should
be necessary. HACS component version is 0.16.10 for matching packages, but its
existing scoped-subscription backend code is unchanged from 0.16.9.

## Getting it
Install the publicly signed `app-release.apk` and the matching HACS
integration from the [public v0.16.10 release](https://github.com/chadakenn/Kellies-Voice/releases/tag/v0.16.10). They are separate
downloads. Existing users should update the APK in place to retain login and
pairing. No release is created by opening a PR.

## Not included
Experimental Development update-channel selection, follow-up listening, wake
words, actionable announcement buttons and the Frigate screensaver dashboard
remain outside this stable release. Known Philips microphone input issue
#71, generic spoken timer routing issue #57, and other model-specific QA remain
open. Android force-stop and manufacturer-specific background restrictions may
still prevent automatic restarts; manually open Kellie's Voice and choose
**Settings → TV alert status → Resume TV alerts** when necessary.
