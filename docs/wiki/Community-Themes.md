# Community Theme Packs

Custom themes let anyone change the look of Kellie's Voice on Android TV without rebuilding the app.

## Import a theme

1. Get a `.json` theme file (see the [theme gallery](https://github.com/chadakenn/Kellies-Voice/tree/main/themes/community)).
2. On the TV: **Settings → Overlay & appearance → Community Themes → Import Theme**.
3. Use the system file picker to select the JSON.
4. Preview or Apply the theme.
5. **Restore Default** returns to Copper Glass.

## Create a theme

Copy `themes/community/template.json`, edit the colors and ID, then import it locally to test.

See [themes/community/CONTRIBUTE.md](https://github.com/chadakenn/Kellies-Voice/blob/main/themes/community/CONTRIBUTE.md) for how to share your theme via pull request.

## Safety

- Themes are JSON data only.
- Invalid files, low contrast, or unsafe content are rejected.
- Pairing credentials and other settings are never modified.
- Built-in themes always remain available.
